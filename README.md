# Lanwork

Windows 11 x64 桌面效率工具。快捷键呼出居中搜索条，搜索应用、文件、待办和便签，以 `+` 或 `/note` 开头时直接收集待办或便签；热角呼出面板，内含待办、便签、文件收纳、GitHub 和设置。

没有「今日」页。界面只显示名称、数量、时间和状态。番茄钟的规则见产品规格，未定参数补齐前不写代码。
