Lanwork __VERSION__

## 更新

自 v0.2.0 以来。

### 收纳网页引用

收纳可以保存网页引用。从 Chrome 或 Edge 把地址栏上的锁图标，或页面里的链接，拖进收纳页或收纳分组悬浮窗。一条引用保存网址、标题和网站图标。只保存引用：浏览器里的标签不关闭、不移动，页面正文也不写进数据目录。拖放里如果同时带有虚拟的 `.url` 文件，不把它存成路径，也不读取其中的文件内容。

标题取这个 `.url` 文件名去掉末尾的 `.url`。页面链接的标题是链接文字。没有分组时，与拖入文件相同，先创建名为「收纳」的分组。

全部收纳里，同一网址只保留先拖入的那一条。比较前会去掉首尾空白，把协议和主机名改成小写，并去掉路径末尾的一个 `/`。`HTTP://Example.COM/a/` 与 `http://example.com/a` 是同一条。再次拖入，包括拖进另一个分组或悬浮窗，不新增，也不改已有条目的网址、标题、图标和所在分组。`http` 与 `https`、路径里其余字符的大小写不同，仍然是两条。删掉之后可以再拖入。

搜索结果里会出现这些引用。标题或网址命中时，类型是「网页」，排在便签之后、文件之前。打开后，默认浏览器打开保存的网址。

条目保存成功之后，会在后台获取网站图标，不挡住保存。收纳页或收纳悬浮窗列出这条、本地还没有图标时也会再取；打开这条时若还没有图标，再试一次，不挡住打开。优先使用页面声明的站点图标，取不到再试站点根上的 `/favicon.ico`。取不到或缓存写不进去时，图标位留空，条目仍在，也不显示「路径不存在」。图标放在数据目录里可以删掉再重建的缓存中，不进入导出和备份。搜索结果不使用这份图标。一键浏览器扩展还不在这一版里。

### 待办悬浮窗

待办页上的「悬浮」打开全程序唯一的待办悬浮窗。已经打开时，再次点「悬浮」只把焦点给这个窗口。窗口列出全部清单里的待办，含已完成。勾选未完成的条目会把它标为完成；带周期的会生成下一次，与在待办页上完成相同。取消勾选已完成的条目会取消完成。逾期条目的整行文字是红色；到期日就是今天时不算逾期。窗口里不能新建，也不能改标题、日期或所属清单。没有要列出的待办时，只显示「没有待办」。

窗口始终在其他窗口之上，没有钉住按钮。可以贴边，也可以和便签、收纳悬浮窗叠在同一叠。位置、大小、贴边和叠页会记下，并随导出和备份走。关闭窗口不删除待办。不在叠里时，重启后不会自己打开。

### 悬浮窗留在屏幕里

不贴边的便签、收纳和待办悬浮窗，在拖动松手、按记住的位置再打开、改变大小，或内容把窗口撑大之后，整扇都留在所在显示器的工作区里。叠在一起时共用这一份位置和大小，同样留在工作区里。贴边的窗口仍贴在屏幕边上，不拉回工作区。

把窗口拖出屏幕的左边、右边或上边再松开，会先回到工作区边缘，然后收成贴边把手。底边拖出去只回到工作区，不贴上边。窗口在越出的方向上几乎铺满工作区时，贴越出的那一侧，不改贴对侧。只改大小时越出工作区，回到工作区里，不因此贴边。

### 叠页圆点

0.2.0 的说明写的是：展开并且至少有两页时，窗口下方正中有一排小圆点。这一版改为窗口下方靠左的彩色圆点，与窗口左边缘对齐，紧贴窗口下沿，画在内容区外面。颜色按页序循环：红、黄、绿、蓝、紫、橙、粉、青，第九页回到红。当前页不透明，并有一圈细白光圈；其余页更透，鼠标停在上面时稍亮。点一个圆点换到那一页。把某一个圆点拖出去，那一页就拆成独立的悬浮窗。左右方向键翻页、拖标题栏移动整叠，以及收起把手上表示页数的小点，仍和以前一样。

### 搜索条里的应用

在有本地文件的应用结果上，Ctrl+Enter 和 Ctrl+Shift+Enter 会以管理员身份运行，由系统显示 UAC 提示。取消 UAC 后不显示错误。没有本地可执行文件时，这两个快捷键无效。

在应用结果上右键，菜单依次是：以其他用户身份运行、以管理员身份运行、打开文件所在文件夹、打开目标文件夹、隐藏。没有快捷方式目标时，「打开目标文件夹」仍在菜单里，但是不可用。没有本地可执行文件时，前两项不可用。菜单打开时，Alt+1 到 Alt+5 选择这些项，不再打开搜索结果。

选择「隐藏」后，该应用不再出现在搜索结果里。设置页「隐藏的应用」里点「恢复」之后，可以再次搜到。

### 检查更新

设置页显示当前版本。启动之后会在后台查看 GitHub 上 Lanwork 的最新正式版，之后每过一天再查一次。点「检查更新」会马上再查一次。没有更新时显示「已是最新版本」。有更新时，托盘图标上有一个小标记，设置页显示新版本和发行说明。不会自动下载，也不会自动安装。

安装版可以点「更新」。程序下载对应的 `Lanwork-Setup-<版本>.exe`，用同一发布里的 `latest.json` 核对 SHA-256，通过之后才退出，静默安装，再启动 Lanwork。安装不修改用户数据。校验失败、下载失败或安装起不来时，不替换当前程序，并显示错误。安装程序没有成功结束时，下次启动显示「安装失败」。便携版只显示「打开发布页」。网络失败时显示「检查更新失败」，不安装。

## 安装版

主要下载：`Lanwork-Setup-__VERSION__.exe`

按当前用户安装，不需要管理员权限。不安装 WebView2，也不安装 Windows App Runtime。开始菜单里的 Lanwork 快捷方式带通知用的 AppUserModelID 和激活 CLSID。卸载会去掉这些注册项，以及开机启动里名为 Lanwork 的项，不会删除文档中的 Lanwork 数据目录。

压缩包里是同一套程序文件，不含安装程序。
