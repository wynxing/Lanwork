# 扩展页与插件

本文规定扩展页和插件的可见行为。与 [product.md](product.md) 已经写明的规则冲突时，以 product.md 为准。番茄钟的计时规则以 product.md「番茄钟」为准。本文规定它如何作为官方插件出现，以及插件悬浮窗如何加入已有的最上层、贴边和叠页。实现排在 v0.2.0 之后，状态见 [roadmap.md](roadmap.md)。现在没有这部分代码。技术验证表里还没有对应项；没有通过记录之前，不写依赖本规格的界面。

2026-10-15 另有悬浮窗工具规格，见 [tools.md](tools.md)。番茄钟在那边是第一个内置工具，带沙箱里的 Lua。两份规格如何并存，待定。在这确定之前，本文对扩展页的规定保持不变。

运行时不引入 Vue、Tauri 或 WebView2。插件不带可执行文件，宿主也不加载插件目录里的动态库。

## 扩展页

**入口。** 面板上的「扩展」标签。标签顺序是待办、便签、收纳、扩展、设置。默认标签仍是待办。

**可见内容。** 顶上是分类标签。第一版是「全部」「官方」「已导入」。是否再按悬浮、托盘、仅后台分类，待定。

分类下面每个插件一行：

| 列 | 内容 |
| --- | --- |
| 名称 | 清单里的名称 |
| 短说明 | 插件作者写在清单里的一行说明 |
| 形态 | 「悬浮」「托盘」或「仅后台」 |
| 开关 | 启用或停用 |
| 「⋯」 | 菜单里是「卸载」和「设置」 |

没有插件时只显示「没有插件」。页面上有「导入」。这一项可以点击，也接受把插件文件夹拖放到这项上。拖到页面其他位置是否同样开始导入，待定。

**动作。** 分类标签只筛选下面的行。开关立即生效，重启后保持。「⋯」打开菜单。清单里没有设置项时，菜单里不出现「设置」。点「导入」，或把文件夹拖到「导入」上，进入同一条导入流程。

**禁止。** 在这一页放功能介绍或使用步骤。用网页视图画这一页。

**验收。** 面板标签是待办、便签、收纳、扩展、设置。点「扩展」打开这一页。每个已安装插件占一行，行上有名称、短说明、形态、开关和「⋯」。没有插件时只有「没有插件」和「导入」。把文件夹拖到「导入」上之后，先出现全部权限；没有全部接受之前不安装。

## 菜单

官方番茄钟的「设置」打开设置里已有的工作时长、休息时长和长休息时长，沿用同一份配置。取值范围仍按产品规格「番茄钟」和「设置」。

导入的插件如果在清单里声明了设置项，设置项能有哪些控件，待定。

「卸载」只出现在导入的插件上。官方插件可以停用，菜单里没有「卸载」。卸载前要确认。确认后停用该插件、关掉它的悬浮窗，并删除数据目录里的那份副本。用户导入前的原文件夹留在原路径。

停用番茄钟时，正在进行的计时停止，与关闭番茄钟窗口相同。再次启用时没有上一次的剩余时间。

## 导入

**入口。** 「导入」。点击，或把文件夹拖到这项上。

**可见内容。** 读到清单后，列出插件名称和它申请的权限。每条权限是一句白话，不显示内部标识。不能逐条勾选。

| 申请 | 界面句子 |
| --- | --- |
| 只读取待办 | 「读取你的待办」 |
| 写入待办，或同时读取并写入 | 「读写你的待办」 |
| 只读取便签 | 「读取你的便签」 |
| 写入便签，或同时读取并写入 | 「读写你的便签」 |
| 系统通知 | 「发送通知」 |
| 网络 | 「联网」 |

**动作。** 用户接受全部权限后才安装。不能只接受其中几条。未全部接受则不安装，数据目录里不留下这份插件。正在等待同意时再拖入另一份，不开始第二次导入。

安装把插件文件夹复制到数据目录下的 `plugins/<id>/`。用户原来的文件夹留在原路径。程序使用数据目录里的副本。

同一 `id` 已经安装时再导入怎么处理，待定。拖入的不是含清单的文件夹时，不安装，并显示错误。压缩包是否接受，待定。

**禁止。** 未同意就复制进数据目录。导入时读取收纳里的文件内容。把插件写进 MayDolist 的目录。安装时移动用户原来的文件夹。

**验收。** 接受全部权限之后，该插件出现在「已导入」和「全部」里。清单里 `enabledByDefault` 为真时开关是开的，省略时开关是关的。拒绝或未全部接受时，列表不变，`plugins/` 里没有它，原来的文件夹还在原路径。界面上看到的是「读写你的待办」这样的句子，看不到 `todo.write`。申请网络时，句子是「联网」。

## 插件包

第一版只有声明式插件。一个文件夹里有一份清单，以及一份由宿主绘制的界面描述。界面描述的文件名和格式，待定。宿主解析之后用 Slint 绘制。描述里不带脚本。

第三方插件不能自带计时或其他程序逻辑。声明式界面除了官方番茄钟已经由产品规格写明的动作之外，还能绑定哪些动作，待定。

清单是文件夹里的 `manifest.json`。

| 字段 | 含义 |
| --- | --- |
| `schemaVersion` | 数字。当前为 1。更高则拒绝安装 |
| `id` | 单个路径分量，规则与数据文件的 id 相同。官方番茄钟是 `lanwork.pomodoro` |
| `name` | 行上的名称 |
| `description` | 一行短说明 |
| `icon` | 插件文件夹内的相对路径。文件格式待定。没有图标或文件缺失时，行上不画图标，仍然可以安装 |
| `form` | `float`、`tray` 或 `background`。界面分别显示「悬浮」「托盘」「仅后台」 |
| `floatSize` | 仅 `float`。`width` 和 `height` 是逻辑像素。番茄钟这两项的数值待定 |
| `permissions` | 申请的权限，见下表 |
| `enabledByDefault` | 可以省略。省略时导入后为关。官方番茄钟为真 |

不认识的 `form`，或 `schemaVersion` 高于 1，则不安装，并显示错误。

### 权限

| 权限 | 界面句子 | 允许 |
| --- | --- | --- |
| `todo.read` | 读取你的待办 | 读取待办。若同时有 `todo.write`，界面只显示「读写你的待办」 |
| `todo.write` | 读写你的待办 | 按现有待办命令新建、修改、完成、取消完成和软删除。删除进入回收站 |
| `note.read` | 读取你的便签 | 读取便签。若同时有 `note.write`，界面只显示「读写你的便签」 |
| `note.write` | 读写你的便签 | 按现有便签命令新建、修改和软删除。删除进入回收站。保存仍带修订号 |
| `notify` | 发送通知 | 发系统通知。安静时段和合并补发按产品规格「待办」 |
| `network` | 联网 | 用户接受后，宿主才可以为这个插件联网。插件自己不打开网页视图。第一版没有另行声明的联网动作时，不发出请求 |

清单里出现不认识的权限时，不安装。不提供收纳、文件内容、配置、备份、token 和启动应用的权限。`todo.write` 和 `note.write` 不能永久删除。

仅后台的插件没有窗口。启用之后，除了已同意的权限之外还能做什么，待定。

托盘形态在托盘菜单里增加一项，文字是插件名称。点这一项之后发生什么，待定。

### 沙箱

界面在宿主进程里绘制，只使用清单里声明并且用户已经同意的权限。同意之外的读取和写入不发生。

插件文件夹里放了可执行文件或动态库时，宿主不运行、不加载。不打开网页视图。

## 悬浮窗

`form` 为 `float` 的插件，启用后可以有一个悬浮窗。这个窗口加入便签悬浮窗、收纳悬浮窗和待办悬浮窗已有的行为：始终在最上层，贴屏幕外侧收成把手，以及叠页。规则以产品规格「便签」「收纳」和「待办」为准。那里已经标成待定的项，插件悬浮窗沿用，不在这里另定。

插件悬浮窗可以和便签悬浮窗、收纳悬浮窗、待办悬浮窗落在同一叠里。窗口不点击穿透。

停用或卸载时关掉这个窗口。番茄钟停用时同时停止计时。

## 官方番茄钟

第一个官方插件是番茄钟，并作为声明式插件的参照。

计时对象、阶段、暂停、跳过、完成、关闭即停止、不保存计时记录、到点通知和安静时段，都按产品规格「番茄钟」。宿主里只有这一套计时。扩展页负责把它列出、启用和停用。

它随程序提供，出现在「官方」和「全部」。形态是「悬浮」。默认启用。没有「卸载」。停用之后，即使已经指定了当前待办，也不能开始计时。

参照清单：

```json
{
  "schemaVersion": 1,
  "id": "lanwork.pomodoro",
  "name": "番茄钟",
  "description": "当前待办的计时",
  "icon": "icon.png",
  "form": "float",
  "floatSize": { "width": null, "height": null },
  "permissions": ["todo.read", "notify"],
  "enabledByDefault": true
}
```

`floatSize` 的宽和高仍待定。参照清单里这两项先写 `null`，`null` 不是已经选定的尺寸。图标格式待定。界面上只显示当前待办标题和计时状态，以及产品规格已经写明的关闭和折叠。它不申请 `todo.write`，不能在这个窗口里改待办。

启用状态保存在数据目录。已安装插件的列表、每个插件在 `plugins/<id>/` 的副本，以及启用状态，都进入导出和备份。导入后，已安装的插件和开关与导出时一致。官方番茄钟随程序提供，导出记下它的启用状态。token 仍不进入导出和备份。

## 禁止

- 宿主执行插件自带的代码、脚本或动态库。
- 运行时引入 Vue、Tauri 或 WebView2。
- 未展示权限就安装。
- 插件读取或修改收纳中的文件，或把用户文件复制进数据目录当作收纳。
- 为官方番茄钟另写一套时长。
- 在扩展页增加「今日」或 Focus。

## 验收

面板标签是待办、便签、收纳、扩展、设置。点「扩展」打开扩展页。分类可以切到「全部」「官方」和「已导入」。番茄钟在「官方」里占一行，形态是「悬浮」，默认开着。「⋯」里有「设置」，没有「卸载」。「设置」改的是工作时长、休息时长和长休息时长，范围仍是 1 至 120 分钟和 1 至 60 分钟。关掉番茄钟后再启用，没有上一次的剩余时间。

导入一份含清单的文件夹时，先看到全部权限，句子是白话。申请待办写入时显示「读写你的待办」，申请网络时显示「联网」。全部接受后才出现在列表里。拒绝或未全部接受时不出现。清单里写了不认识的权限时不安装。插件目录里的可执行文件不会被运行。导出再导入之后，已安装的插件还在，启用状态与导出前相同。

番茄钟的悬浮窗在其他普通窗口之上。拖到屏幕外侧的左、右或上边松开，收成把手，规则与便签悬浮窗相同。把它拖到便签、收纳或待办悬浮窗上，重叠超过一半后松开，可以进入同一叠。
