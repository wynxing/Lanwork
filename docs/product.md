# 产品规格

本文规定可见行为。与 [architecture.md](architecture.md) 冲突时，行为以本文为准，机制以架构文档为准。实现状态见 [roadmap.md](roadmap.md)。仓库里还没有这些界面。

平台：所有 Windows 11 x64。背景 API 不可用的版本自动以纯色背景运行。数据目录独立，默认 `%USERPROFILE%\Documents\Lanwork`。不读取、不导入 MayDolist 的数据目录。

沿用是指行为与 MayDolist 1.3.11 的对应模块一致，并写在下面。不是指把 MayDolist 的代码或 WebView 界面搬过来。

## 全局规则

1. 界面文字只允许名称、数量、时间、状态和错误。禁止欢迎语、功能介绍和使用步骤。空列表只显示一行对象名，例如「没有待办」。
2. 不存在「今日」或 Focus 界面、标签、托盘入口和通知落点。
3. 搜索框中的字符只参与搜索。唯一例外是搜索条里以收集前缀开头的输入，见「快速收集」。除此之外，创建待办或便签必须走待办页、便签页里的明确动作。
4. 中文输入法组合未上屏时，Enter 不执行搜索结果，也不提交收集。
5. 同时最多一条「当前待办」。它由用户在待办行上指定，写入该条目并在重启后保留。指定另一条则替换。清除后，番茄钟按其规则停止。
6. 写盘失败时保留原文件，并在触发该动作的界面显示错误。
7. 系统关闭透明效果、处于节电模式、透明渲染失败或背景 API 不可用时，亚克力背景改为与主题一致的纯色。不为此显示提示。

## 搜索条

**入口。** 默认热键 `Ctrl+Alt+M`。搜索条已显示时，再按一次收起。

**可见内容。** 无边框圆角窗口，系统亚克力背景。出现在光标所在显示器的水平中央，上边缘位于工作区高度 25% 处。只有一个输入框。搜索时，结果列表在输入框下方展开；输入框为空时只显示输入框。收集时显示的内容见「快速收集」。

**动作。** 搜索结果的显示和打开见「搜索」，收集见「快速收集」。失焦或输入框为空时按 Esc 收起，不退出进程。搜索时输入框非空，Esc 只清空输入。收起后再打开，输入框为空；未提交的收集文本例外，见「快速收集」。

**禁止。** 标签栏、说明文字、最近使用列表。

**验收。** 再按热键收起。组合输入期间 Enter 不打开结果。从搜索条打开待办或便签结果后，搜索条收起，面板打开并定位到该条。

## 面板

**入口。** 热角默认右上，可设为左上、左下、右下或关闭。多显示器时，每一块显示器上的所选角都可以触发。有全屏应用时不触发热角。光标进入所选热角并连续停留 350ms 后打开面板；光标离开该角后才允许再次触发。停留期间重复打开不发生。面板热键默认不设置，可在设置中指定。托盘右键菜单可打开面板、打开设置、新建便签、刷新 GitHub，以及「退出」。选择「退出」后结束进程；退出前先按「便签」保存未写入的修改。

**可见内容。** 无边框圆角窗口，系统亚克力背景。标题栏为产品名、标签和关闭。标签顺序固定：待办、便签、收纳、GitHub、设置。默认标签是待办。标签下方是搜索框，再下方是当前内容。

**动作。** 关闭按钮、失焦和搜索框为空时的 Esc 收起面板，不退出进程。搜索框非空时，Esc 只清空搜索并恢复收起搜索前的标签内容。收起后再打开：搜索框为空，标签保持收起前的选择。

**禁止。** 说明段落、玻璃透明度滑块、「今日」标签。

**验收。** 热角关闭后，光标进角不打开面板，搜索条热键仍可用。多显示器时，在任一块显示器的所选角停留后打开面板。有全屏应用时，光标进角不打开面板。组合输入期间 Enter 不打开结果。收起不结束进程。托盘「退出」后进程结束。

## 搜索

**入口。** 搜索条或面板搜索框获得字符。搜索条里以收集前缀开头的输入不搜索，见「快速收集」。面板搜索框不识别收集前缀，输入一律作为搜索。两处的搜索结果和动作相同。

**可见内容。** 在面板里，标签栏保留，内容区改为结果。每条显示图标、名称和类型。文件和文件夹结果在名称下方用一行小字显示路径；其它结果选中后才显示路径或所属位置。名称中与输入相同的部分加粗：不区分大小写，只加粗第一处；名称里没有这段原文时不加粗，例如靠拼音、首字母或模糊匹配命中的结果。结果类型为应用、待办、便签、文件、文件夹、浏览器和网页搜索。分组顺序固定：输入是有效 `http` / `https` 时浏览器结果在最前，其后是应用、待办、便签、文件和文件夹，网页搜索在最后。无效地址不产生浏览器结果。

有输入时，结果最后始终有一条网页搜索，名称为「搜索 Google：<输入>」。搜索引擎默认 Google，设置里可改为必应或百度，名称随之为「搜索必应：<输入>」或「搜索百度：<输入>」。这一条不计使用次数。它是否占 20 条上限的名额，待定。

当前可见的前 9 条结果右侧各显示一个按键提示，从上往下依次为 Alt+1 至 Alt+9。结果区滚动后只露出一部分的行是否编号，待定。

组内按命中类型排序：完全匹配、前缀、全拼、首字母、子串、模糊。同一条结果只出现一次，类型取其中最前的一种。使用频率只在同一种命中类型内决定先后，不跨类型比较。每次从搜索结果打开一项，该项的使用次数加 1。同组内、同一种命中类型按使用次数从高到低排列。完全匹配始终排在其他命中类型之前。最多显示 20 条。按分组顺序（浏览器、应用、待办、便签、文件、文件夹）每组先取至多 8 条；名额还有剩余时，再按这一分组顺序把前面组剩下的结果取完，再取后面的组，直到满 20 条或没有更多结果。

待办只匹配未完成条目的标题，选中后显示所属清单。便签匹配标题、标签和正文，选中后显示所在的一行正文。回收站中的待办和便签不出现。Everything 未运行或未就绪时，文件和文件夹结果改由 Windows Search 索引提供，只按名称匹配，范围限于 Windows 已建立索引的位置。两者都不可用时，结果区显示「文件索引不可用」，应用、待办和便签结果保留。

开始菜单里的 `.url` 游戏链接作为应用收录。只收地址以 `steam://run/`、`steam://rungameid/` 或 `com.epicgames.launcher://apps/` 开头的链接。普通网页 `http` / `https` 的 `.url` 不收录。

**动作。** 上下键移动选择。鼠标悬停在一条结果上时选中该条；单击直接打开，等同 Enter。Enter：应用、文件、文件夹和浏览器结果用 Windows Shell 打开；网页搜索结果用默认浏览器打开所选搜索引擎的搜索页，搜索词为输入去掉首尾空白；待办结果打开面板、切到待办并定位该条；便签结果打开面板、切到便签并打开该篇。文件和文件夹结果上 Ctrl+Enter 打开所在目录；便签结果上 Ctrl+Enter 悬浮该便签。Alt+1 至 Alt+9 直接打开当前可见的第 1 至 9 条结果，等同选中该条后按 Enter；组合输入期间无效，和 Enter 一致。新输入覆盖旧结果，旧查询不得在新输入之后刷回。在面板里清空搜索框后，恢复进入搜索前的标签内容。

便携应用与系统来源是同一启动目标时，搜索结果只显示一条，名称用用户填的名称。别名的目标不在索引里时是否单独成条，待定。

应用结果可以右键「隐藏」。隐藏后不再出现在搜索结果。设置「应用」页列出已隐藏的应用，可以恢复。应用结果支持「以管理员身份运行」和「打开所在文件夹」，入口是右键菜单和快捷键。Ctrl+Shift+Enter 以管理员身份运行。Ctrl+Enter 打开所在文件夹，与文件和文件夹结果打开所在目录一致。商店应用和游戏链接等没有本地文件的结果不显示这两个动作，对应快捷键无效。

**禁止。** 把不带收集前缀的搜索词存成待办或便签。在结果上编辑待办或便签。搜索文件内容。复制或移动命中的文件。

**验收。** 连续输入时，中间结果不覆盖最后一次输入。Everything 不可用时，已建立索引位置中的文件仍能按名称搜到；Windows Search 也不可用时，仍能打开应用、待办和便签。Windows Search 回退时，只有正文命中的文件不出现。无效 URL 没有浏览器动作。已完成的待办和回收站中的条目不出现。从搜索结果打开待办会打开面板并定位该条（安装版与点击到期通知落到同一位置；便携版通知不定位，但搜索打开仍定位）。从结果打开一项后，该项使用次数增加；同组同类中次数更高的排在前面。完全匹配仍排在其他命中类型之前。开始菜单中的 Steam、Epic 游戏链接能作为应用搜到；普通网页 `.url` 不出现在应用结果里。隐藏后的应用不在搜索结果中，在设置「应用」页恢复后可以再次搜到。有输入时最后一条是「搜索 Google：<输入>」，打开后默认浏览器显示 Google 的搜索页，该条使用次数不增加；设置改为必应或百度后，这一条随之改变。输入有效 URL 时，浏览器结果仍在第一条，网页搜索在最后。Alt+2 打开当前可见的第二条；组合输入期间按 Alt+数字不打开结果。

索引来源、拼音、条数和图标缓存见架构文档。

## 快速收集

**入口。** 搜索条输入框的内容以收集前缀开头。没有独立窗口和独立热键。

收集前缀只有两种，都必须位于输入开头：

- `+` 或全角 `＋`：收集待办。前缀后的空白忽略。
- `/note`：收集便签。后面必须是空白或结束；`/notes` 这类紧挨着的词按搜索处理。

**可见内容。** 收集时不显示搜索结果，输入框下方只有一行预览和一行错误。待办预览显示「待办」、标题，以及识别出的到期日。便签预览显示「便签」和标题，没有标题时显示「无标题」。

**动作。** `+` 之后的文字按下面的规则解析。无日期前缀，或日期前缀无法识别：在收件箱创建待办，不写入到期日。能识别并写入到期日的前缀只有：`今天`、`今日`、`明天`、`明日`、`后天`、`周X`、`星期X`、`下周X`（X 为一、二、三、四、五、六、日、天）、`N天后`（N 为 1 至 365）、`月底`、`月末`。日期前缀必须是收集前缀之后的第一个词（中间的空白忽略），并且后面是空白或结束；`+ 明天性计划` 这种紧挨着的词不写到期日。日期前缀之后的文字作为标题。`下周` 后面不是上述星期字时，整句当作普通待办标题。

单独的 `周X` 或 `星期X` 取今天之后最近的一次，不含今天。今天是周三时，「周三」是下周三。本周已经过去的星期，取下一周的那一天。`下周` 从周一开始，`下周X` 是当前这一周（周一至周日）之后那一周里的星期 X。`月底` 和 `月末` 是本月最后一天；今天就是该日时，指今天。

`/note` 创建便签，并打开该便签的悬浮窗进行编辑；`/note` 后的文字作为便签标题。创建成功但悬浮窗没有打开时，只重新尝试打开悬浮窗，不重新创建便签。仍失败则提示「便签已保存，悬浮失败」，该便签留在列表里。

Enter 提交，然后清空输入框并收起搜索条。按 Esc、失焦或再按热键收起时，保留未提交的收集文本，下次打开搜索条时原样恢复。提交失败时保留文本并显示错误。收集前缀之后只有空白时，Enter 不创建记录。

**禁止。** 在面板搜索框里收集。收集时向文件索引发查询。

**验收。** 不以收集前缀开头的输入按 Enter 不创建任何记录。只输入 `+` 时 Enter 不创建记录。组合输入期间 Enter 不提交。收集文本收起后再打开仍在。删掉前缀后，输入框立即回到搜索。便签已创建但悬浮失败时，重试不产生第二篇；仍失败时显示「便签已保存，悬浮失败」，列表里有这一篇。

## 待办

**入口。** 待办标签。安装版的到期通知被点击时，打开面板、切到待办并定位该条。便携版的到期通知只显示提醒，点击不定位。

**可见内容。** 清单列表。系统收件箱清单存在且不重复创建。条目显示标题；有到期日、周期、GitHub 来源或关联收纳分组时显示对应标记。逾期数量可出现在托盘徽标上，数量为 0 时不显示徽标。

**动作。**

| 动作 | 结果 |
| --- | --- |
| 新建、改标题、排序 | 写入对应清单 |
| 完成 | 条目标为完成；带周期规则时生成下一次，直到重复截止日。没有重复截止日时照常生成下一次。在重复截止日当天完成，不再生成下一次。每月重复的 31 日，在没有 31 日的月份落到该月最后一天；下一次仍按原来的日子（1 月 31 日、2 月 28 日或 29 日、3 月 31 日）。原来的日子记在周期上。旧记录没有该字段时，用当前到期日的日子。29 日或 30 日在目标月不存在时落到哪一天仍待定 |
| 软删除 | 进入回收站。恢复后回到原清单；原清单已删除时，回到默认清单 |
| 永久删除 | 只在回收站中。进入回收站满 30 天后自动清除 |
| 到期日、提醒、周期 | 字段为每天、每周、每两周、每月。提醒到点发系统通知。睡眠或关机期间错过的多条提醒，恢复后合并成一条补发，可以展开查看各条。安静时段内不弹出；时段结束后，错过的多条提醒同样合并成一条补发，可以展开查看 |
| 打开来源 | 仅 `http` / `https`；其他协议拒绝 |
| 设为当前 / 清除当前 | 遵守全局规则 5 |
| 打开关联收纳 | 仅当有收纳分组关联该条时可用；切到收纳并选中该分组，关联多个分组时选中第一个 |
| 处理模式 | 只作用于收件箱未完成条目，一次一条 |

处理模式的按键：

| 键 | 结果 |
| --- | --- |
| `1` | 到期日设为今天 |
| `2` | 到期日顺延，天数由设置指定，默认 3，允许 1 至 30 |
| `3` | 选目标清单后移动，保留 GitHub 来源 |
| `4` | 完成 |
| `5` | 软删除 |
| Esc | 退出处理模式，回到清单 |

处理模式不另存一套数据。光标按条目 id 前进。写盘失败时停在当前条并显示错误。组合输入不触发 `1` 至 `5`。

**禁止。** 在待办页展示其他模块的聚合列表。

**验收。** 重启后到期日、周期、来源和当前标记仍在。旧记录缺少这些字段时仍能打开。安装版的通知点击落到待办中的该条，不打开一个名为今日的页面。便携版的通知点击不定位。每月重复的 31 日，在没有 31 日的月份落到该月最后一天，下一次仍回到原来的日子。没有重复截止日时，完成后仍生成下一次。在重复截止日当天完成后没有下一次。清单里不能永久删除。回收站中超过 30 天的待办被清除。原清单已删除时，恢复回到默认清单。睡眠或关机后错过的多条提醒合成一条，展开后能看到各条。安静时段内不弹出提醒，结束后同样合成一条。

## 便签

**入口。** 便签标签，或托盘「新建便签」。

**可见内容。** 便签列表和正文。可显示置顶和标签。

**动作。** 新建、编辑、打标签、按标签筛选、置顶、删除。按文字查找使用全局搜索。停止编辑 1 秒后自动保存。删除后进入回收站，保留 30 天，可以恢复或永久删除。悬浮：打开只含该便签正文的独立窗口；每篇便签记住自己的悬浮窗位置和大小，再次打开时使用。同一篇已经有悬浮窗时，再次悬浮只聚焦该窗口。关闭悬浮窗后正文仍留在便签列表。多个悬浮窗可以同时存在。同一篇在面板和悬浮窗里同时修改时，后保存的一方弹出提示，由用户选择保留哪个版本。关闭便签窗口或退出程序时，先自动保存未写入的修改。保存失败时提示，可以选择重试，或放弃修改后继续关闭或退出。

**禁止。** 悬浮窗里的说明文字。关闭悬浮窗时删除便签。

**验收。** 停止编辑满 1 秒后写入。自动保存失败时正文还在窗口里，并显示错误。关闭窗口或退出时若保存失败，可以重试或放弃修改。关闭后再开，正文与关闭前最后一次成功保存一致。同一篇已有悬浮窗时再次悬浮，焦点回到该窗口，位置和大小仍是记住的值。删除后列表里不再显示，回收站里可以恢复；超过 30 天被清除。后保存的一方不直接覆盖，先出现选择版本的提示。

## 收纳

**入口。** 收纳标签，或待办上的「打开关联收纳」。

**可见内容。** 分组列表，每组显示名称和条目数；关联了待办的分组同时显示该待办标题。选中分组后列出条目，每条显示图标和名称；选中条目后显示完整路径。路径不存在的条目显示「路径不存在」。没有分组时只显示「没有分组」。

**动作。**

| 动作 | 结果 |
| --- | --- |
| 新建、重命名、排序分组 | 写入该分组 |
| 删除分组 | 确认后删除分组和其中的引用，不动原文件 |
| 拖入文件或文件夹 | 加入当前选中的分组；没有分组时先创建名为「收纳」的分组。可一次拖入多个。只保存路径引用，不移动、不复制原文件 |
| 重复拖入 | 同一分组内同一路径不新增；不同分组可以各有一条 |
| Enter 或双击 | 用 Windows Shell 打开 |
| Ctrl+Enter | 打开所在目录 |
| 拖出到资源管理器或其他应用 | 按原路径提供文件，只允许复制和创建快捷方式，不允许移动 |
| 移除引用 | 从分组删掉该条，不删除原文件 |
| 关联待办 / 解除关联 | 关联时弹出搜索框，输入关键字筛选待办，点击一条即关联。一个分组至多关联一条待办；一条待办可以被多个分组关联 |

关联只用于跳转。待办完成或进入回收站不改变分组；待办被永久删除后，关联自动解除。分组只包含用户拖入的引用。

**禁止。** 扫描系统正在打开的文件。自动归集。内容搜索。同步。把文件复制进数据目录。绑定真实文件夹。拖出时移动原文件。

**验收。** 移除引用或删除分组后，原文件仍在原路径。重复拖入不产生第二条。失效路径有可见错误。拖到资源管理器后，原文件仍在原路径。写盘失败时拖入不产生半条引用，并显示错误。反复切换收纳标签、拖入和拖出，句柄数不持续增加。关联待办时出现搜索框，关键字缩小列表，点击后该分组显示这条待办的标题。

## GitHub

**入口。** GitHub 标签，或托盘「刷新 GitHub」。

**可见内容。** 按已追踪仓库列出 open 的 PR 和 Issue。每条显示仓库、编号、标题，以及这些状态中实际命中的项：需要处理、需要 Review、CI 失败、CI 进行中、没有检查、无权限读取、长期未更新、Draft。CI 进行中、没有检查、无权限读取各自单独显示，不算 CI 失败。长期未更新的天数由设置指定，默认 14；设为 0 则不标这项。离线时列表仍显示上次快照，并标「离线缓存」。

**动作。** 用系统浏览器打开该条。转为待办：成功后条目进入收件箱，标题含仓库、编号和原标题，来源类型为 `github-pr` 或 `github-issue`。刷新单仓库或全部。筛选：我的、被提及、被分配、参与，以及上述状态。多个筛选同时使用时按并集，满足任一即显示。忽略和钉住被记住。

追踪仓库的添加入口在 GitHub 页。输入 `owner/repo`，使用本机 `gh` 已登录的身份。格式不对时提示，并说明正确格式是 `owner/repo`。移除追踪后删除该仓库的快照；已经关联的待办保留，但与该仓库断开关联。

「我的」是本机 `gh` 当前用户创建的 PR 和 Issue。「被分配」是分配给该用户的。「被提及」是提到该用户的。「参与」是该用户评论过的 PR 和 Issue。「需要 Review」是请求该用户审查的 PR。「需要处理」是请求该用户审查的 PR，以及该用户创建且 CI 失败的 PR。「CI 失败」是检查未通过的 PR。

认证只用本机 `gh`。程序不保存 GitHub token。`gh` 不可用或网络失败时保留已有快照，不清空其他仓库。来源已关闭或已合并且设置允许时，关联待办标为完成；来源重新打开时不自动把待办改回未完成。存在未完成的关联待办时，GitHub 列表不显示该 PR 或 Issue；待办完成或删除后，若远程仍为 open 且命中当前筛选，则重新出现。这次隐藏不改 watchlist 和 cache。关联待办上仍可打开来源。

**禁止。** 应用内登录页。在 GitHub 页写入除「转为待办」和忽略、钉住以外的待办字段。

**验收。** 未登录时，待办和便签仍可编辑。转为待办失败时不产生半条待办。导出的数据包不含 token。格式不对时提示并说明正确格式是 `owner/repo`，不增加追踪。移除追踪后，该仓库的快照不再出现，关联待办仍在且不再关联该仓库。只满足多个筛选中的一项时仍然显示。请求当前用户审查的 PR 同时标「需要处理」和「需要 Review」。当前用户创建且 CI 失败的 PR 标「需要处理」。当前用户评论过的 PR 或 Issue 出现在「参与」中。CI 进行中、没有检查、无权限读取各自单独显示，不标成 CI 失败。

## 设置

**入口。** 设置标签，或托盘「设置」。

**可见内容与动作。** 热角、搜索条热键、面板热键（可留空）、安静时段、开机启动、主题、网页搜索引擎（Google、必应、百度，默认 Google）、GitHub 刷新间隔、长期未更新天数、来源同步、关闭来源时自动完成待办、处理模式「稍后」天数、番茄钟的工作时长、休息时长和长休息时长、数据目录、备份、导出、导入、回收站。

另有「应用」页：用列表添加、编辑、删除便携应用和别名。已隐藏的应用也列在这一页，可以恢复。应用索引的手动刷新入口在这一页。

另有「关于与更新」页：检查更新、进度、安装和重启。

主题只切换明、暗、跟随系统。亚克力由系统绘制。不提供搜索条、面板或便签的透明度百分比。背景 API 不可用时的纯色见全局规则 7。

每天第一次启动时自动备份一次。自动备份和手动备份合计最多保留 7 份，超出时删除最旧的。

导入先显示内容概览。确认后先备份当前数据，再替换。校验失败时当前数据不变。替换过程中进程中断时，下次启动恢复为导入前的数据，并显示「导入未完成」。导出不含 token、环境变量和日志。

导出包含收纳分组和其中的路径引用，不含被引用的文件。

回收站列出已删除的待办和便签。恢复、永久删除和 30 天自动清除见「待办」和「便签」。

**验收。** 非法热键不覆盖原来可用的热键，并显示错误。搜索条热键与面板热键相同则拒绝保存。导入中断后原数据仍可打开。同一天第二次启动不再自动备份。备份超过 7 份时，删除最旧的，直到不超过 7 份。「应用」页可以添加、编辑、删除便携应用和别名，可以手动刷新应用索引，也可以恢复已隐藏的应用。「关于与更新」页可以检查更新，并看到进度、安装和重启。

## 番茄钟

**入口。** 用户对当前待办启动番茄钟。没有当前待办时，这个动作不可用。

**可见内容。** 独立小窗。只显示当前待办标题和计时状态。可关闭、可折叠。窗口不点击穿透。

**动作。** 计时对象始终是当前待办。用户清除当前待办或指定另一条时，本次计时停止。关闭窗口即停止计时。不保存计时记录。

默认工作 25 分钟、休息 5 分钟。工作与休息交替，每完成 4 轮工作后的休息为长休息，默认 15 分钟。工作时长、休息时长和长休息时长都可以在设置里修改。工作时长允许 1 至 120 分钟。休息时长和长休息时长允许 1 至 60 分钟。

暂停冻结剩余时间，之后可以继续。跳过进入下一阶段，本轮不记为完成。完成记为完成一轮并进入休息。暂停、跳过和完成都不改变待办的完成状态。

到点发系统通知。安静时段内不弹出。时段结束后，错过的通知按「待办」中安静时段结束的方式合并补发：多条合成一条，可以展开查看。

**禁止。** 根据前台窗口或打开的文件推断当前待办。云同步。在这个窗口编辑待办列表。

**验收。** 未指定当前待办时无法开始。切换当前待办后，窗口不再显示上一条的剩余时间。暂停后再继续，剩余时间与暂停时相同。跳过不增加完成轮数。完成一轮后待办的完成状态不变；满 4 轮后进入长休息。关闭窗口后再打开，没有上一次的剩余时间。安静时段内到点不弹出通知。工作时长只接受 1 至 120 分钟，休息时长和长休息时长只接受 1 至 60 分钟。

- 应用内 GitHub 登录，或保存 GitHub token
- 云同步、移动端、macOS
- 文件内容搜索
- 记录用户未拖入的文件
- 收纳绑定真实文件夹、移动或复制收纳中的文件、嵌入桌面的收纳盒
- 从 MayDolist 数据目录迁移
